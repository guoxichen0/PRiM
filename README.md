# PRiM-score for Multiple Root Cause Identification

This repository contains Python code for generating nonlinear Gaussian
structural equation model data and running PRiM-score methods to identify
multiple root causes under additive mean-shift interventions.

## Project structure

```text
.
|-- prim_score/
|   |-- graphs.py               # CPDAG learning, MEC enumeration, and local IDA
|   |-- mechanisms.py           # Gaussian Process (GP)/OLS mechanisms and PRiM scores
|   |-- methods.py              # PRiM methods, CPDAG-2#R, and NOTEARS-2#R
|   |-- notears.py              # Linear/nonlinear NOTEARS structure learning
|   `-- __init__.py             # Public Python API
|-- example.ipynb               # Minimal reproducible nonlinear example
|-- requirements.txt            # Python dependencies
|-- pyproject.toml              # Package configuration
`-- README.md
```

## Installation

Create a Python environment and install the package:

```bash
git clone <YOUR-GITHUB-URL>
cd <YOUR-REPOSITORY>

python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate

python -m pip install --upgrade pip
python -m pip install -e ".[notears]"
```

The `notears` extra installs PyTorch and the official NOTEARS implementation.
If NOTEARS is installed in a separate environment, set its Python executable:

```bash
export PRIM_NOTEARS_PYTHON=/path/to/notears/environment/bin/python
```

## Quick start

Open and run the example notebook:

```bash
jupyter notebook example.ipynb
```

The example will:

1. Generate a nonlinear additive Gaussian SEM with 8 variables.
2. Generate 500 normal samples and 10 anomalous samples.
3. Apply mean-shift interventions of strength `delta = 1.5` to `X0` and `X4`.
4. Estimate a CPDAG from the normal data using PC+RCIT.
5. Learn a separate nonlinear DAG using NOTEARS-MLP.
6. Run PRiM-Score-Standard, PRiM-Score-Local, and PRiM-Score-NOTEARS.
7. Print the true roots, predicted roots, Recall@2, node scores, and runtimes.

For the included random seeds, the expected root-cause output is:

```text
True root causes:                 X0, X4
PRiM-Score-Standard:              X0, X4
PRiM-Score-Local:                 X0, X4
PRiM-Score-NOTEARS:               X0, X4
Recall@2:                         1.0
```

## Main components

### Data generation

`example.ipynb` contains the nonlinear Gaussian SEM used in the example. The
structural functions use `sin` and `tanh`, while every structural noise term is
Gaussian. The anomalous data are generated by shifting the noise means of the
true root-cause variables.

The example settings are:

```python
N_NORMAL = 500
N_ANOMALOUS = 10
DELTA = 1.5
TRUE_ROOTS = ["X0", "X4"]
```

### Graph learning

`prim_score/graphs.py` contains:

- `learn_cpdag()`: estimates a CPDAG with PC+RCIT by default;
- `learn_cpdag(..., model_type="linear")`: estimates a CPDAG with XGES;
- `enumerate_consistent_dags()`: enumerates DAGs in a CPDAG equivalence class;
- `possible_parent_sets()`: extracts locally valid IDA parent sets;
- graph validation, parent extraction, topological layers, and reachability.

The default nonlinear CPDAG estimate is obtained with:

```python
from prim_score import learn_cpdag

graph_result = learn_cpdag(normal_data)
cpdag = graph_result["cpdag"]
```

### PRiM-score methods

`prim_score/methods.py` contains the five methods included in this repository:

- `standard_prim()`: Algorithm 1 using global MEC enumeration;
- `local_prim()`: Algorithm 2 using local IDA parent sets;
- `prim_notears()`: PRiM scores on a NOTEARS DAG;
- `cpdag_2r()`: CPDAG ordering of the top-2R squared-Z candidates;
- `notears_2r()`: NOTEARS ordering of the top-2R squared-Z candidates.

Algorithm 1 and Algorithm 2 can be run as follows:

```python
from prim_score import local_prim, standard_prim

standard_result = standard_prim(
    normal_data,
    anomalous_data,
    cpdag,
    top_k=2,
)

local_result = local_prim(
    normal_data,
    anomalous_data,
    cpdag,
    top_k=2,
)
```

The default conditional mechanism is an exact Gaussian process fitted using
all normal observations. Additional GP options only need to be supplied when
the defaults should be changed.

### PRiM-Score-NOTEARS

`prim_score/notears.py` learns the nonlinear NOTEARS-MLP DAG in an isolated
process. This keeps PyTorch separate from PC+RCIT and the main PRiM workflow.

```python
from prim_score import learn_notears_dag_isolated, prim_notears

notears_dag = learn_notears_dag_isolated(normal_data)

notears_result = prim_notears(
    normal_data,
    anomalous_data,
    notears_dag,
    top_k=2,
)
```

### PRiM score

`prim_score/mechanisms.py` fits each conditional mechanism on normal data only
and reuses the fitted mechanism on anomalous data. For node `i`, the score is
the absolute residual mean shift divided by the normal residual standard
deviation.

The default mechanism settings are:

```python
mechanism = "gp"
gp_max_samples = None
gp_random_state = 0
gp_optimizer = None
```

Use `mechanism="linear"` to replace the GP with ordinary least squares.

## Input format

`normal_data` and `anomalous_data` must be pandas DataFrames with identical
column names and column order.

Graph matrices use parent-row/child-column encoding:

```text
G[parent, child] = 1 and G[child, parent] = 0   means parent -> child
G[parent, child] = 1 and G[child, parent] = 1   means parent -- child
```

## Output

Each method returns a dictionary containing at least:

```python
{
    "predicted_roots": ["X0", "X4"],
    "ranking": ["X0", "X4", "..."],
    "scores": {"X0": 1.97, "X4": 1.11, "...": 0.0},
}
```

Algorithm 1 additionally returns the selected candidate DAG. Algorithm 2
returns the selected and possible local parent sets for every node.
